## ?? Como sincronizar entre a Empresa e o PC Pessoal

Siga estes passos sempre que for começar ou terminar de trabalhar:

### 1. No computador que você ESTÁ USANDO (Terminou o trabalho):
No terminal, execute:
git add .
git commit -m "Resumo do que você fez hoje"
git push origin main

### 2. No OUTRO computador (Vai começar o trabalho):
Ao abrir o projeto, a primeira coisa a fazer é:
git pull origin main
*Isso trará todas as mudanças que você fez no outro PC para este.*
